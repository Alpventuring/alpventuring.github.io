# ALPVENTURING link sayfası

Yayın adresi: https://alpventuring.github.io

Instagram ve YouTube bio'sundaki link sayfası. Sitenin tamamı tek dosya: `index.html`.

## Sık yapılan değişiklikler

- Ekipman: `index.html` içindeki `const GEAR` bölümü (Yaz / Kış / Uzun yol) ve `const FILMING` (çekim ekipmanı).
- İş birliği e-postası: `const CONTACT_EMAIL = ""` satırına adresi yaz; sayfada kopyalanabilir bir satır olarak çıkar.
- Yayın günü ve saati: `const RELEASE` (şu an Pazar 20:00, Türkiye saati).

Değişiklik `main` dalına gönderildikten sonra site birkaç dakika içinde güncellenir.
